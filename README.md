# Jongeume 블로그

[https://jongeume.github.io](https://jongeume.github.io)

크래프톤 정글 여정과 개발 공부를 기록하는 블로그. [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 테마 기반.

## 글 작성

`_posts/YYYY-MM-DD-title.md` 형식으로 작성하고, front matter에 `categories`·`tags`를 지정한다.

```markdown
---
title: 제목
date: 2026-09-01 09:00:00 +0900
categories: [에세이]
tags: [정글, 회고]
---
```

## 배포

`main` 브랜치에 push하면 GitHub Actions가 빌드·배포한다. (Pages 소스: GitHub Actions)
